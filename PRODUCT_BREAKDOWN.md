## Core Users
- Creators
- Viewers
- Communities
- Developers

## Main Workflows
1. Creator starts stream
2. Viewer joins stream
3. Viewer sends chat
4. Creator checks analytics

## Product Problems
- Scalability
- Real-time communication
- Authentication
- Stream interruptions

## Features
| Module                | Features                                |
| --------------------- | --------------------------------------- |
| Authentication        | Login, Register, Profile, Security      |
| Creator               | Stream Creation, Dashboard, Stream Keys |
| Streaming             | RTMP, Processing, Adaptive Streaming    |
| Viewer                | Watch, Follow, Share, Playback          |
| Chat                  | Live Messaging, Presence, Emojis        |
| Moderation            | Delete, Ban, Timeout, Moderators        |
| Discovery             | Search, Categories, Trending            |
| Analytics             | Audience, Health, Engagement            |
| Recordings            | Replay, Manage, Library                 |
| Notifications         | Live Alerts, Updates                    |
| Settings              | Profile, Appearance, Security           |
| Infrastructure        | Self-hosting, Scalable Architecture     |
| Admin *(recommended)* | User & Platform Management              |

## Out of Scope
- Payments
- Ads
- Mobile apps
